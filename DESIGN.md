# Touchcraft editor

An operating workspace for sustained visual programming. The installed Craft family supplies the visual authority: charcoal panels, restrained borders, compact controls, and bright but limited selection color.

Use purple for image operator identity and warm white for readable text. The central network is the primary workspace; the left library adds operators, the right pane shows the selected image and its parameters, and transport stays at the bottom. Preview imagery is actual graph output. Phosphor icons use one regular weight and visible labels or tooltips. All actions remain accessible from standard egui controls as well as canvas gestures.

The app icon uses a warm-white Phosphor graph symbol on a periwinkle rounded square, matching the Craft family's tile proportions while retaining an original mark.
