# Touchcraft

<!-- impeccable:product-schema 1 -->

## Platform
macOS desktop

## Stack
User-confirmed: the existing Craft stack, Rust and egui. Phosphor Icons throughout. Local macOS application; no hosted service.

## Product Purpose
An independent implementation of TouchDesigner's visual programming workflow. Connect image operators, inspect live results, edit parameters, control time, and save projects.

## Capabilities and Constraints
The first working slice implements TOP-style image operators: Noise, Circle, Constant, Transform, Level, Composite, and Output. Project files use an original, validated JSON format. TouchDesigner file compatibility and full operator parity remain open work.

## Brand Commitments
Touchcraft. Follow the installed Craft family's dark editor surfaces and rounded app-icon silhouette. Use Phosphor for the app symbol and interface icons.

## Evidence on Hand
Installed TouchDesigner bundle at /Applications/TouchDesigner.app. REA 6.7.0 available in the existing PaperCraft workspace. Primary Derivative documentation informs workflow; research records distinguish direct evidence from inference.
